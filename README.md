## О Проектах

На данный момент на сайте представлены два основных модуля:

### 🚀 JxBooster
Модуль для Magisk/KernelSU, предназначенный для эффективного устранения троттлинга на вашем Android-устройстве. JxBooster интеллектуально управляет системными ресурсами, обеспечивая пиковую производительность для игр и требовательных приложений без перегрева.

**Ключевые особенности JxBooster (версия 3X Final):**
*   Полностью переработанный алгоритм управления частотами.
*   Улучшенная стабильность и совместимость с новыми ядрами.
*   Оптимизация для снижения энергопотребления в простое.
*   Поддержка последних версий KernelSU.

### 🌐 JxZapret
Модуль, помогающий обходить блокировки популярных сервисов (YouTube, Discord, Gemini и др.) на территории России. JxZapret возвращает вам полный доступ к глобальному информационному пространству.

**Ключевые особенности JxZapret (версия 1X Final):**
*   Обновлены списки обхода для актуальных блокировок.
*   Улучшена производительность и снижена нагрузка на систему.
*   Более надежная работа с различными конфигурациями сети.

## Как посмотреть локально

1.  Клонируйте репозиторий:
    ```bash

    ```
2.  Перейдите в папку проекта:
    ```bash
    cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
    ```
3.  Откройте файл `index.html` в вашем веб-браузере.
